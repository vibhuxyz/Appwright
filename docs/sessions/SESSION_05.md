## New Concepts Learned

1. **Single-Route State Reconciliation & Router Normalization:**
   In single-page applications using client-side routers (TanStack Router), having multiple path aliases (e.g. `/` and `/dashboard`) for the same core view causes URL fragmentation, broken bookmarks, and desynchronized browser history. Normalizing at both the route definition level (`beforeLoad` redirect) and layout lifecycle (`history.replaceState`) ensures predictable navigation.
2. **Split-Surface Modal Authentication:**
   Separating visual proof of product capability (showcase carousel on the left) from credential input (auth form on the right) significantly boosts onboarding conversion by demonstrating immediate product value before asking for user data.
3. **Progress-Bar State Synchronization in React:**
   Synchronizing multi-step slide timers with CSS animations requires key-based re-renders or state resets when users manually click a tab, preventing out-of-sync transitions.
